Weekly Report

    
Write your weekly report in Markdown, send it as a properly formatted
       email. Everything runs in this browser tab; nothing is uploaded
       anywhere.

    
    
      
  1. Pick where reports live: a folder on your disk (one
        .md file per week; an empty folder is fine) or this
        browser's own storage. Either is remembered next time.
    2. 
      
  2. New week creates the report below, ready to fill in. One
        ## heading per project with its day count; the total is
        summed for you.
    3. 
      
  3. Copy email, then paste into your mail compose window and send.
        Formatting, links and images come along.
    4. 
    

    
## Project name - 2 days
This week:
- what happened
    - a detail underneath (Tab makes a sub-bullet)

Status:
- Ongoing

Upcoming:
- what comes next

    

      
      
      
    

    
Folder (Chrome, Edge): reports are plain .md
      files you can sync with git or a cloud drive. Browser storage
      (any browser): nothing to set up; Storage… exports a backup zip. Later
      on: History charts days per project across every week, and
      ? lists the editor shortcuts.

    
This browser cannot open folders
      on disk, so reports are kept in browser storage.
