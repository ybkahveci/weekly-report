Weekly Report

Write your weekly report in Markdown, send it as a properly formatted email. Everything runs in this browser tab — reports are read and saved directly on your own disk, nothing is uploaded anywhere.

  1. Pick a folder for your reports — one .md file per week is kept there. An empty folder is fine; the browser remembers it next time.
  2. New week creates the report below, ready to fill in. One ## heading per project with its day count — the total is summed for you.
  3. Copy email, then paste into your mail compose window and send. Formatting, links and images come along.
## Project name — 2 days This week: - what happened - a detail underneath (Tab makes a sub-bullet) Status: - Ongoing Upcoming: - what comes next

Requires Chrome or Edge (the File System Access API is how it reaches your folder). Later on: History totals days per project across every week, and ? lists the editor shortcuts.
